#

<h4 align="center"><b>About me</b></h4>

I started coding out of curiosity. Today, I build software that solves real problems for real users.

I'm a **Software Engineer** currently working at **Grupo GenIA**, with experience in **multi-tenant platforms** and **mission-critical applications**. I've contributed to the development and evolution of long-lived systems: shipping new features, reducing **technical debt**, refactoring **legacy code**, and implementing **architectural improvements** that keep applications maintainable and reliable over time.

I believe good software is the result of **good engineering** decisions, not just good code. That's why I see programming languages as tools rather than identities. I've worked primarily with **PHP**, **Java**, and **Go**, but my focus is always on understanding the problem first and choosing the most appropriate solution for the context.

Outside of work, I enjoy studying and writing about **Software Engineering**, **System Design**, and **DevOps**. Sharing what I learn is one of the ways I keep improving as an engineer.
